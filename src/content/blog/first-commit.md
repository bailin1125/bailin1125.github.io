一直想有个自己的地方写东西，想了很久，2025 年的最后几天终于动手。

## 拖了这么久的原因

不是没时间，是一直在等一个「完美的方案」：等自己会设计、等选好最酷的框架、等想清楚要写什么主题。后来想明白了，这三件事都不会先发生，它们都是写着写着才长出来的。

## 所以就先提交了第一行

```bash
git commit -m "docs: 个人主页设计文档"
```

先有一个能跑的雏形，再慢慢改。这个站本身就是这个想法的产物。

## 写给未来的自己

别等准备好。准备是写出来的，不是想出来的。
