笔记工具换了一圈，最后留下来的反而是最土的办法：一个 Git 仓库，全是 Markdown。

## 为什么是纯文本

- 十年后依然打得开，不依赖任何一家公司的服务；
- diff 友好，改了什么一目了然；
- 随手就能全文搜索，`grep` 比任何搜索框都快。

## 我的目录约定

```
notes/
├── inbox/      # 未经整理的碎片
├── topics/     # 按主题归档的长文
└── journal/    # 按月存放的工作日志
```

唯一的纪律是：想到什么先丢进 `inbox/`，每周清一次，值得留的挪进 `topics/`，不值得的果断删。

## 工具不重要

试过很多花哨的笔记软件，最后发现真正决定产出的不是工具，而是「有没有一个固定的地方接住想法」。Markdown 只是最不容易挡路的那一个。
